# Showcase the .gitignore and .aiignore files

*   `.gitignore` is a standard configuration file that prevents Git from tracking unwanted files (such as local configuration files, logs, or system files like `.DS_Store`) in source control. By default, the AI agent will also read it and ignore these files from being read or scanned.
*   `.aiignore` is a specialized file used by autonomous coding agents (like Antigravity) to filter out files and folders that should not be parsed into the agent's context window. This prevents sensitive credentials, temporary build folders, or large datasets from leaking or wasting model tokens.

## Testing Notes: Managing Cell Unlocks & High Scores

To clear your persistent high score, run the following command in your browser's Developer Tools Console (accessible via `F12` or `Cmd+Option+I` on Mac):

```javascript
localStorage.removeItem('immunity_highscore');
```

To clear both the high score and the top 5 leaderboards, run:

```javascript
localStorage.clear();
```

To quickly unlock both the NK cells and Neutrophils for testing, set your high score to 15,000 points by running the following command in the console, then reload the page:

```javascript
localStorage.setItem('immunity_highscore', '15000');
```

*(Note: Setting this value directly unlocks both cells on the selection screen when clicking "START SYSTEM" without needing to achieve the score in gameplay.)*
