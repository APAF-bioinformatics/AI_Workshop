### PROMPT 1: BACKGROUND GRAPHICAL GRID
"Draw a faint static microscope grid on the 2D Canvas using TWO layers of dotted lines:
- Primary grid (100px spacing): rgba(0, 242, 254, 0.22), dash pattern [3, 15].
- Secondary finer grid (50px spacing): rgba(0, 242, 254, 0.08), dash pattern [2, 24].
This creates a realistic reticle-style microscope eyepiece effect."

### PROMPT 3: FLUID BULLET PHYSICS
"Implement fluid bullet physics. Both player bullets and enemy bullets must simulate movement through a viscous biological medium. Each bullet instance has:
- age (seconds elapsed)
- driftAmp (random 18–32px for player, 12–22px for enemy)
- driftFreq (random 4–7 Hz for player, 3–6 Hz for enemy)
- driftPhase (random)
In each update(dt), lateral drift = driftAmp * cos(age * driftFreq + driftPhase) * dt, added to x position. This makes bullets curve sinusoidally as if buffeted by cytoplasmic flow."

### PROMPT 6: EPISAFE LIFE-LOSS BLINK
"Implement a life-loss blink effect. When the player loses a life, trigger a soft red screen flash (blinkTimer = 0.55s). In the draw loop, compute alpha = sin(ratio * π) * 0.2 where ratio = blinkTimer / 0.55, and fill the canvas with rgba(220, 30, 30, alpha). This creates a smooth bell-curve fade that is visible but will NOT trigger photosensitive epilepsy."

### PROMPT 7: COLUMN-TARGETED BARRIER COLLISION & BOUNDARY CHECKS
"Implement column-targeted hit detection for player bullets and enemy bullets on destructible barriers to allow bullets to pass through destroyed channels without horizontal blocking:
- Determine the exact column 'c' by division of the bullet bounding box's center X coordinate relative to the barrier's start X coordinate. Bullets will only check and collide with block layers in that specific column 'c' and cannot be blocked horizontally by adjacent columns.
- Implement tunneling-resistant boundary checks: player bullets traveling upwards (reverse=true) erode the column starting from the bottom-most active block of column 'c' up, triggering a collision if the bullet's top edge is at or below the bottom-most active block's bottom edge (and the bullet's bottom edge has not completely passed above the barrier's startY); enemy bullets traveling downwards erode the column starting from the top-most active block of column 'c' down, triggering a collision if the bullet's bottom edge is at or above the top-most active block's top edge (and the bullet's top edge has not completely passed below the barrier's bottom edge).
- A single vertical column channel (all 5 layers of column 'c') must be completely destroyed before bullets passing through that column index can traverse the barrier without collision."
